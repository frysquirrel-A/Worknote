현장 협업의 미래,
WorkNote Masterpiece

WorkNote는 서버 유지비 0원이라는 혁신적인 아키텍처 위에, 최신 프리미엄 디자인(Pixel 9a Optimized)을 결합한 현장 관리 솔루션입니다. 구글 드라이브와 로컬 DB를 결합하여 어디서나 멈추지 않는 업무 환경을 제공합니다.

cloud_off

Offline-First

지하, 터널 등 통신 불능 지역에서도 모든 기능이 즉시 작동합니다.

payments

Zero Server Cost

구글 드라이브를 개인 서버로 활용하여 영구적으로 무료 사용이 가능합니다.

security

Secure Sync

데이터 소유권이 사용자 본인에게 있으며, 실시간 클라우드 백업을 지원합니다.

dashboard 홈 대시보드 : 현장 상황실

📊 실시간 달성률 차트

fl_chart를 기반으로 한 인터랙티브 파이 차트입니다. 팀 전체 업무 대비 완료된 업무의 비율을 실시간으로 계산하여 시각화합니다.

🏗️ 프로젝트별 진행도 리스트

각 현장(골조, 전기, 인테리어 등)별로 업무 진행 상황을 개별 막대 그래프로 표시합니다. 어떤 공정이 늦어지고 있는지 한눈에 파악할 수 있습니다.

👥 팀원 아바타 퀵 링크

현재 팀에 소속된 멤버들을 가로 스크롤 아바타 리스트로 보여줍니다. 담당자를 확인하고 소통 탭으로 즉시 연결하는 허브 역할을 합니다.

task_alt 스마트 업무 관리 시스템

Filtering

4-Way 복합 필터링

프로젝트별, 상태별(진행/완료), 중요도별, 기간별(오늘/이번 주) 필터를 조합하여 수천 개의 업무 중 필요한 정보만 즉시 추출합니다.

Sorting

정밀 정렬 시스템

마감일 임박순, 작성일 최신순, 중요도 높은 순으로 리스트를 즉시 재배열하여 업무 우선순위 판단을 돕습니다.

🚩 업무 상세 카드 디테일

  • • 우선순위 깃발: 4단계 색상 구분으로 긴급도 표시
  • • D-Day 카운터: 마감 임박 여부를 자동으로 계산하여 경고
  • • 스와이프 삭제: 직관적인 제스처로 데이터 관리 편의성 극대화

calendar_month 타임라인 스케줄러

🗓️ Table Calendar 연동

단순한 달력이 아닙니다. 업무 데이터베이스와 실시간으로 연동되는 스케줄러입니다.

  • - Event Dots: 업무 마감일이 있는 날짜에 자동으로 컬러 닷 표시
  • - Day Focus: 날짜 클릭 시 하단에 해당일 업무 요약 카드 노출
  • - Sync: 달력에서 업무 완료 시 홈 탭 차트에도 즉시 반영

auto_stories 현장 일지 & 보안 갤러리

📓 작업 일지 (Journal)

매일의 현장 상황을 기록합니다. 작성된 일지는 날짜별로 그룹화되어 타임라인 형태로 보존됩니다. 비공개 설정 기능을 통해 민감한 내용은 본인만 볼 수 있습니다.

📸 보안 갤러리 (Gallery)

Pinterest 스타일의 Masonry Grid 레이아웃을 적용했습니다. 사진 크기에 관계없이 세련되게 배치되며, Pinch-to-Zoom 기능을 통해 현장 하자를 정밀하게 검토할 수 있습니다.

forum 실시간 현장 메신저

"서버 없는 채팅의 구현"

별도의 채팅 서버 없이 구글 드라이브의 폴링(Polling) 기술을 활용해 메시지를 주고받습니다. 팀별로 독립된 채널이 생성되며, 카카오톡 스타일의 익숙한 UI를 통해 현장 팀원들 간의 즉각적인 소통을 지원합니다.

Auto Polling Drive Sync

System Vision

WorkNote Master v0.1은 "협업의 본질은 기록과 동기화에 있다"는 전제하에 개발되었습니다.
Pixel 9a 에뮬레이터 환경에 최적화된 라운드 디자인과 하이브리드 동기화 엔진이 결합된 결과물입니다.

Design Philosophy

모든 UI 요소는 Radius 24~32의 부드러운 곡률을 가지며, Slate-50 배경 위에서 화이트 카드가 붕 떠 있는 입체적인 클린 룩을 지향합니다.

01. Home Tab (Dashboard)

UI 인사말 & 프로필

상단에 한국어 날짜와 사용자 이름을 실시간으로 바인딩하여 개인화된 경험을 제공합니다.

"안녕하세요 ${authProv.currentUser?.name}님! 👋"

Logic 프로젝트 진행 현황

각 프로젝트에 할당된 전체 업무 대비 완료 업무의 비율을 계산하여 LinearProgressIndicator로 시각화합니다.

  • • 데이터 바인딩: taskProv.getFilteredTasks
  • • 계산식: (doneCount / totalCount) * 100

02. Task Tab (Smart Management)

FEATURE 5중 복합 필터 바

MenuAnchor 위젯을 사용하여 위치가 고정된 세련된 필터 시스템을 구축했습니다.

프로젝트별
진행 상태별
중요도별 (상/중/하)
작성일 기간별
담당자별

UI 업무 카드 (Task Card)

정보 밀도를 높인 2분할 레이아웃을 적용했습니다.

  • done_all 좌측 뭉치: 작성/수정/기한/완료 날짜 2열 2행 배치
  • person 우측 강조: '담당' 라벨과 대형 이모지(32sp) 배치

03. Schedule Tab (Timeline)

SYNC 캘린더 연동 로직

table_calendar 패키지를 활용하여 업무 데이터베이스와 실시간 동기화됩니다.

eventLoader: (day) => tasks.where((t) => isSameDay(t.dueDate, day))

마감일이 있는 날짜에는 자동으로 오렌지색 점(Dot)이 표시되어 일정을 놓치지 않게 합니다.

04. Journal & Photo

📓 작업 일지 기록

상단 검색바를 통해 과거 기록을 즉시 검색할 수 있으며, 일별/전체 리스트 모드 전환 기능을 제공합니다.

📸 Masonry 갤러리

사진 비율을 유지하는 핀터레스트 스타일 격자를 적용했습니다. 날짜별로 사진이 자동 그룹화됩니다.

05. Messenger (Polling)

SYSTEM 서버리스 채팅 원리

구글 드라이브의 JSON 파일을 5초마다 읽어와 새로운 메시지를 감지하는 Polling 방식을 사용합니다.

_chatProvider.startPolling(); // 5초 간격 드라이브 체크
Note 데이터 소모를 줄이기 위해 앱이 백그라운드로 가면 폴링이 자동 중단됩니다.

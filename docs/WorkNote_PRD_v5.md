# WorkNote PRD (v5)
- 목적: Android Studio Gemini(코드 어시스트)가 **바로 수정/확장 가능한 수준의 요구사항 + 수용기준(AC)** 을 갖도록 정리
- 대상: 개발자(관리자/오너 포함), Gemini/LLM 코드 어시스트
- 작성일: 2026-02-15 (Asia/Seoul)
- 코드베이스 기준: `lib_refactored_v5` (Feature-first + Core shared widgets)

---

## 1. 제품 개요
WorkNote는 팀 기반으로 **업무(Task)**, **일지(Journal)**, **일정(Calendar)**, **사진(갤러리)**, **소통(채팅)** 을 한 앱에서 관리하는 협업 도구다.

핵심 특징:
- 로컬 우선(offline-first): Hive 기반 로컬 저장
- 선택적 Google Drive 연동: 일부 JSON 동기화
- 팀 기준 필터링: 현재 선택된 팀(teamId) 기준으로 화면/데이터가 분리됨

---

## 2. v5 변경점(요약)
### 2.1 업무(Task) 탭 — 카드/그룹/정렬 UX 대개편
- 기본 카드 디자인을 **원래 카드(TaskCard) 리스트**로 복구 (요청사항 반영)
- 상단 아이콘으로 **카드 디자인 선택(리스트 ↔ 갤러리)** 가능
- 날짜 그룹 헤더(예: `2026-02-17`) 탭 시 **해당 그룹 접기/펼치기**
- 카드 바로 위 컨트롤:
  - **그룹 단위:** 일 / 주 / 월 / 분기 / 년
  - **정렬 기준:** 작성일 / 수정일 / 기한 / 일정 / 완료일
  - **정렬 방향:** 최신순(↓) / 오래된순(↑)
- 갤러리 카드(TaskMasonryCard) 개선
  - 카드 높이를 늘리고, **작성/기한/일정(기간)/완료/작성자** 메타를 카드 내부에 노출
  - 같은 그룹 내부는 **가로 스크롤**로 카드 탐색

### 2.2 용어/데이터 변경 — 스케줄 → 일정(기간)
- UI 용어를 **스케줄 → 일정**으로 통일
- 업무의 일정은 단일 날짜가 아니라 **기간(DateTimeRange)** 로 설정
  - task_meta에 `scheduleStart`, `scheduleEnd` 저장
  - 레거시 `scheduleDate`는 읽기 호환 후 저장 시 제거

### 2.3 업무 카드의 달력 아이콘(일정 단축 수정)
- 업무 카드에 달력 아이콘 추가
- 아이콘 탭 → **일정 설정 시트**에서
  - 일정 포함 여부 토글
  - 일정 기간(시작~끝) 선택

### 2.4 일정 탭 — 개인 일정(기간) 작성/수정/삭제
- 일정 탭에서 업무 일정(기간)뿐 아니라 **개인 일정(기간)** 을 생성 가능
- 개인 일정 저장: Hive `schedules` box (untyped Map)
- 캘린더 마커/일별 리스트에 업무+개인 일정을 통합 표시

### 2.5 일지(Journal) 탭 — 작성 버튼 UX
- 일지 작성 버튼을 하단 고정 버튼 **“+일지작성”** 으로 변경

### 2.6 업무 ↔ 일지 연결 및 조회
- 일지 작성 시 **관련 업무(선택)** 를 항상 지정 가능
- 업무 상세(TaskDetail)에서 **관련 일지 목록(미리보기)** 제공
  - 항목 탭 → 일지 상세 열람

### 2.7 일지 생성 시 Assertion 크래시 방지
- DropdownButtonFormField의 `initialValue`가 `items`에 없을 때 발생하는 assertion 방지
  - relatedTaskId / projectId를 안전값(safe id)로 보정
- 저장 시 try/catch로 실패 메시지 SnackBar 표시

## 3. 목표(Goals)
1. 업무 탭을 “기본 카드(리스트)”로 직관화하되, **갤러리 카드도 선택 가능**하게 제공
2. 그룹/정렬/접기/핀 UX로 대량 업무를 빠르게 탐색
3. “일정”을 기간 기반으로 정리하여 캘린더 사용성을 높임
4. 일정 탭에서 개인 일정까지 관리하여 현장/개인 스케줄을 한 화면에서 처리
5. 업무-일지 연결을 통해 보고/기록 흐름을 끊기지 않게 함

## 4. 기능 요구사항 + 수용 기준(AC)

### 4.1 업무(Tasks) 탭
#### FR-T5-1 카드 디자인 선택
- 기본은 **리스트(TaskCard)**
- 상단 아이콘으로 **갤러리(TaskMasonryCard)** 로 전환 가능
- AC
  - 전환은 즉시 반영
  - 앱 재시작 후 상태 유지(선택) — *v5에서는 메모리 상태, 추후 Hive로 저장 가능*

#### FR-T5-2 그룹 접기/펼치기
- 그룹 헤더 탭 시 해당 그룹의 카드 목록이 접히거나 펼쳐진다.
- AC
  - 접힌 상태에서 헤더는 유지되며, 화살표 아이콘이 상태를 표시

#### FR-T5-3 그룹 단위 선택
- 그룹 단위는 일/주/월/분기/년
- 그룹 기준일은 `TaskProvider.effectiveTimelineDate(task)`
  - 일정 포함 + 일정 시작이 존재하면 일정 시작
  - 아니면 기한(dueDate)
- AC
  - 주간 그룹은 “주간 yyyy-MM-dd ~ yyyy-MM-dd” 형태로 표시
  - 월/분기/년 그룹은 해당 기간 라벨이 표시

#### FR-T5-4 정렬 기준 선택
- 정렬 기준: 작성일/수정일/기한/일정/완료일
- 정렬 방향: 최신순/오래된순
- AC
  - 기준 변경 시 동일 그룹 내 아이템 정렬이 변경
  - 최신순일 때 값이 큰 날짜가 위(또는 좌측)로

#### FR-T5-5 갤러리 카드(가로 스크롤)
- 갤러리 선택 시 각 그룹 내부는 가로 스크롤로 업무 카드 탐색
- AC
  - 화면에 2장의 카드가 동시에 보이는 폭을 유지(반폭 카드)
  - 카드 높이가 증가하여 작성/기한/일정/완료/작성자 정보를 확인 가능

#### FR-T5-6 카드의 일정(기간) 수정
- 카드의 달력 아이콘을 탭하면 일정 설정 시트가 열린다.
- AC
  - 일정 포함 토글
  - 날짜 범위 선택
  - 저장 즉시 일정 탭/업무 탭 표시 반영

---

### 4.2 일정(Calendar) 탭
#### FR-C5-1 업무 일정 표시(기간)
- 일정 포함된 업무는 기간 기반으로 캘린더에 표시
- AC
  - 특정 날짜 선택 시, 해당 날짜에 걸치는 업무가 리스트에 표시

#### FR-C5-2 개인 일정 CRUD
- 일정 탭에서 개인 일정을 기간으로 생성/수정/삭제
- AC
  - “일정 추가” 버튼으로 생성
  - 리스트 아이템 탭으로 수정 시트 열기
  - 수정 시트에서 삭제 가능

---

### 4.3 일지(Journal) 탭
#### FR-J5-1 작성 버튼 라벨 변경
- 작성 버튼은 하단 고정 버튼 “+일지작성”
- AC
  - 버튼 탭 시 일지 작성 시트 노출

#### FR-J5-2 업무 연결(관련 업무)
- 모든 종류의 일지에서 관련 업무를 선택할 수 있다.
- AC
  - 드롭다운에 없는 값이 initialValue로 들어오면 자동으로 null 처리하여 크래시 방지

#### FR-J5-3 업무 상세에서 관련 일지 조회
- 업무 상세 화면에서 해당 업무와 연결된 일지를 목록으로 표시
- AC
  - 항목 탭 → 일지 상세 열람
  - 최신 업데이트 순으로 정렬

## 5. 데이터 스키마/마이그레이션 메모
### 5.1 task_meta (Hive untyped)
- includeInSchedule: bool
- scheduleStart: ISO8601 String
- scheduleEnd: ISO8601 String
- completionReportAt: ISO8601 String
- legacy: scheduleDate(단일) — 읽기 호환 후 저장 시 제거

### 5.2 schedules (Hive untyped)
- id, teamId, userId, userName, title, note
- start, end (ISO8601)
- isAllDay, createdAt, updatedAt

## 6. 파일 구조(요약)
- `core/` : 테마/팔레트 + 공용 위젯
- `domain/` : 모델
- `data/` : Hive 어댑터, Drive/Local 서비스, 앱 초기화
- `features/<feature>/state` : Provider
- `features/<feature>/ui` : 화면
- `features/<feature>/ui/widgets` : 컴포넌트

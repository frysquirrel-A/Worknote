# Gallery 기능 설계 (features/gallery)

이 문서는 **사진(Gallery)** 탭의 역할과 데이터 흐름을 요약합니다.

## 목표

- 업무/일지/현장에서 촬영한 이미지를 팀 단위로 모아 조회한다.
- 리스트/그리드 등 다양한 형태의 갤러리 UI를 제공한다.
- 추후 Drive/클라우드 연동(업로드/다운로드)을 확장할 수 있는 구조를 유지한다.

## 핵심 파일

- `lib/features/gallery/ui/gallery_tab.dart`
  - 사진 탭 메인 UI
  - 현재는 샘플/로컬 데이터 기반의 갤러리 표현에 초점

## 데이터 구조

- 현재 버전은 “갤러리 UI 기반”을 먼저 안정화한 상태.
- 향후 확장 포인트
  - Hive: `gallery_items` 박스 추가(이미지 메타데이터 저장)
  - 파일 저장소: 앱 내부 저장소/서버/Drive 연동

## UI 가이드

- 상단 컨트롤/필터는 Tasks/Journals와 톤을 맞춰 **둥근 박스 + 약한 그림자** 스타일 유지
- 썸네일은 동일 비율로 크롭(일관된 격자감)
- 빈 상태(empty state) 안내 문구 제공

## 디버그/테스트 팁

- 우선은 “이미지 목록이 많을 때” 스크롤 성능을 확인
- 추후 실제 파일 핸들링 도입 시, iOS/Android 권한 처리(사진 접근/저장) 체크 필요

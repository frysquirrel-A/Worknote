# System / Admin 기능 설계

이 문서는 시스템 모니터 및 관리자용 데이터 처리 로직을 정리합니다.

## 핵심 로직: 데이터 초기화 및 샘플 생성
- **파일**: `lib/data/services/app_reset_service.dart`
- **주요 기능**: `reset()` 메서드를 통해 기존 데이터를 모두 소거하고, 테스트에 최적화된 다중 팀 샘플 데이터를 생성함.

### 1. 다중 팀 독립 생성 (Isolation)
초기화 시 3개의 서로 다른 성격을 가진 팀을 생성하여 필터링 및 격리 로직을 테스트함.
- **마스터피스 건설 팀**: 건설 현장 테마 (기사, 안전관리자, 자재담당, 공무).
- **가족 모임 (본가)**: 가사/행사 테마 (막내, 총무, 운전기사 등).
- **개발 동아리**: IT 프로젝트 테마 (프론트엔드, 백엔드, UI/UX 디자인).

### 2. 샘플 데이터 구성
- **유저**: 각 팀별로 고유한 ID와 이름, 역할을 부여하여 생성.
- **프로젝트**: 팀의 테마에 맞는 프로젝트(예: 리모델링, 앱 출시 등)를 각각 2~3개씩 생성.
- **업무(Tasks)**: 팀당 20개씩, 총 60개의 업무를 자동 생성.
  - 다양한 상태(진행중/완료), 중요도, 기한, 담당자를 무작위로 조합.
  - 일부 업무에는 '일정 포함(Schedule Meta)' 데이터가 포함되도록 설정.

## 운영 및 테스트 가이드
- **Drawer 진입점**: 좌측 상단 드로어의 "데이터 초기화" 버튼을 통해 수행.
- **데이터 격리 테스트**: 홈 화면이나 업무 탭에서 팀을 전환했을 때, 다른 팀의 프로젝트나 업무가 노출되지 않는지 확인하는 용도로 활용.

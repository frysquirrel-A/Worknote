# Home 기능

## 목적
- 팀의 현재 상태를 한 화면에서 요약 (팀 선택 / 뷰 설정 / 팀원 / 프로젝트 / 오늘 업무)
- 팀원 프로필 팝업에서 DM(메신저)로 바로 이동 및 협업 상태 확인

## 주요 UI 요소
- **팀 선택 박스**
  - Home 상단 인사 영역 아래 배치.
  - 탭하면 BottomSheet에서 팀 목록 선택 및 `TeamProvider.switchTeam()` 호출.

- **화면 뷰 설정 카드 (신설)**
  - **글로벌 토글**: '묶어보기(Pager)'와 '각각보기(Separated)' 모드 전환.
  - **슬라이드 뷰**: 전체 섹션에 가로 스와이프 레이아웃을 일괄 적용하는 기능.
  - **상태 유지**: `AutomaticKeepAliveClientMixin`을 적용하여 탭 이동 후에도 뷰 설정 및 스크롤 위치가 유지됨.

- **팀원 리스트 & 프로필 (개선)**
  - 팀원 아바타 클릭 시 **레퍼런스 디자인 기반 프로필 팝업** 오픈.
  - 중앙 정렬된 대형 아바타, 이름, 역할 정보 및 하단 꽉 찬 '메시지 보내기' 버튼 배치.
  - 메시지 보내기 클릭 시 해당 팀원과의 DM 스레드로 즉시 이동.

- **대시보드 레이아웃**
  - **묶어보기 (Pager)**: 한정된 공간에 탭 형태로 정보를 집약. 하위 슬라이드 뷰와 메인 페이지 스와이프 간 제스처 충돌을 방지하기 위해 묶어보기 상태에서는 페이지 스와이프를 잠금(터치 탭으로만 이동).
  - **각각보기**: 각 섹션을 독립된 카드로 나열하며, 섹션별로 '슬라이드 뷰' 개별 토글 가능.

- **데이터 격리**
  - 선택된 팀에 따른 프로젝트 및 업무 필터링 로직이 적용되어 팀 전환 시 정보가 섞이지 않음.

이번 v5에서 실제로 바뀐 것

업무 탭 기본 카드 복구 + 디자인 선택 + 그룹/정렬 강화
  • 업무 카드(원래 카드)가 기본으로 돌아왔습니다. (리스트형)
  • 상단 아이콘으로 갤러리 카드도 언제든 선택 가능합니다.
  • 날짜/기간 그룹 헤더를 누르면 해당 그룹이 접힘/펼침됩니다.
  • 카드 바로 위에서 그룹 단위(일/주/월/분기/년)와 정렬 기준(작성일/수정일/기한/일정/완료일)을 바꿀 수 있습니다.
  • 갤러리 모드에서는 같은 그룹 내부가 가로 스크롤되며, 카드가 더 길어져 메타정보를 더 많이 보여줍니다.
일정 탭 개인 일정(기간) 작성/수정/삭제
  • 업무의 일정은 이제 기간(시작~끝)로 관리됩니다.
  • 업무 카드의 달력 아이콘을 눌러 일정 포함/기간을 바로 수정할 수 있습니다.
  • 일정 탭에서 개인 일정도 기간으로 추가/수정/삭제 가능합니다.
일지 탭 버튼 UX + 업무 연결
  • 일지 작성 버튼이 +일지작성으로 변경되었습니다.
  • 모든 일지에서 관련 업무를 선택할 수 있고, 업무 상세에서 관련 일지를 바로 열람할 수 있습니다.

사용법(운영자 기준)

업무 탭
(1) 상단 아이콘(리스트/그리드)으로 카드 디자인을 바꿉니다.
(2) 그룹(일/주/월/분기/년)과 정렬 기준을 바꿔 빠르게 탐색합니다.
(3) 날짜 라벨을 누르면 그 날짜/기간 그룹이 접힙니다.
업무 일정(기간) 관리
업무 카드의 달력 아이콘 → 일정 포함 토글 → 기간 선택 → 저장
일정 탭에서 해당 기간에 걸쳐 표시됩니다.
일지 생성 오류(Assertion) 대응
관련 업무/프로젝트가 삭제되어도 드롭다운 initialValue가 안전하게 보정되도록 수정했습니다.
저장 실패 시 SnackBar로 원인 메시지를 표시합니다.

기능 체크리스트

영역 완료 내용 비고
업무 카드 디자인 기본 카드(TaskCard) 복구 + 갤러리 카드 선택 토글 상단 아이콘으로 즉시 전환
업무 그룹/정렬 일/주/월/분기/년 그룹 + 작성/수정/기한/일정/완료일 정렬 + 방향 그룹 헤더 접기/펼치기 포함
일정 기간 업무 일정은 기간(DateTimeRange)로 관리 (scheduleStart/scheduleEnd) 레거시 scheduleDate 읽기 호환
일정 개인 일정 일정 탭에서 개인 일정(기간) CRUD Hive untyped box: schedules
일지 버튼/연결 +일지작성 버튼 + 관련 업무 연결 + 업무 상세에서 관련 일지 미리보기/열람 일지 저장 크래시 방지

향후 개선 제안(선택)

  • 카드 디자인/그룹/정렬 설정을 Hive에 저장하여 앱 재시작 후에도 유지
  • 일정 탭 개인 일정에 시간(시작/종료)까지 추가(현재는 기간 기반)
  • 업무 카드 자체에 연결된 일지 개수/최근 1개 미리보기 노출
  • 대량 데이터에서 TableCalendar eventLoader 최적화(날짜별 캐시)

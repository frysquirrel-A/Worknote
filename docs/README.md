- **가장 먼저 볼 문서**: `00_overview.md`
- 작업 체크리스트: `AI_CHECKLIST.md`
- 폴더 맵: `folders/01_lib_tree.md`, `folders/02_folder_map.md`
- 기능별 상세: `features/`

> 이 문서는 코드와 함께 유지하는 것을 전제로 합니다. 폴더/파일이 추가되면 해당 섹션을 함께 갱신해주세요.

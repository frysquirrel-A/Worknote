# WorkNote 개선 체크리스트 (AI 작업용)

이 체크리스트는 “다른 AI가 이어서 작업할 때” **현재 상태/남은 작업**을 빠르게 파악하기 위한 문서입니다.

## 0) 공통 원칙

- **아키텍처/폴더 구조는 유지**: `UI → Provider → Hive` 흐름을 깨지 않음
- 불필요한 대규모 리팩토링 금지(파일 이동/대규모 rename 최소화)
- 기능 삭제/비활성화 금지(미완이면 TODO/FLAG로 남기기)

## 1) 빌드/분석(필수)

- [ ] `flutter clean` / `flutter pub get` 후 `flutter run` 빌드 성공
- [ ] `dart analyze` 에러 0개(가능하면 경고도 최소화)
- [ ] Hive 박스 오픈 순서 문제 없음(부팅 시 box not found 방지)

- [x] 인사 영역에서 팀 선택 가능(드롭다운/선택 UI) → `TeamProvider.switchTeam()`

## 3) 업무(Tasks) 탭 UX (리뷰 PDF 3~6번)

- [x] 상단 필터/컨트롤을 한 덩어리 카드로 통합

  - 모든 필터는 BottomSheet 방식으로 통일
  - 필터 박스는 2줄(라벨/값), 둥근 모서리 + 약한 그림자
- [x] 상태 필터는 “전체/진행중/완료”만
- [x] 업무 카드 UI 정리(중요도/작성자/담당자/계획 표시 안정화)
- [x] 상세 시트 오버플로우/컨트롤러 dispose 이슈 방지
- [x] “계획(일정)” 연동: 캘린더 아이콘 터치 시 포함 토글
- [x] 샘플 데이터 50개 이상 생성 로직 유지/확장
